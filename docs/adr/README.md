# Architecture Decision Records

> This directory documents all significant architectural decisions made for Commerce Insight AI.
> Each ADR captures the context, decision, and consequences of a choice.

---

## ADR Format

Each ADR file follows this naming: `{NNN}-{short-title}.md`

### Template

```markdown
# ADR-NNN: Title

**Status**: [Proposed | Accepted | Deprecated | Superseded by ADR-NNN]
**Date**: YYYY-MM-DD

## Context
What problem or situation motivated this decision?

## Decision
What was decided?

## Consequences
What are the positive and negative consequences?
```
